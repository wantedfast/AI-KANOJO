# AI-KANOJO 胶囊前端产品设计审核

## Audit scope

- Surface: 520×108 常驻胶囊、休眠态、`⋮` 菜单、Listening 与 Thinking 状态。
- User goal: 用户无需阅读说明即可唤醒 AI 女友、说话并理解当前状态，同时不被低频控制打扰。
- Evidence: `01-idle.png`、`02-menu.png`、`03-listening.png`、`04-thinking.png`，均为本次审核重新捕获的 1280×720 浏览器画布。

## Overall verdict

休眠态的尺寸和基础气质已经可用，但交互架构仍像“桌面播放器控制条”，不是语音桌宠。`⋮` 菜单没有解决真实任务，唤醒后还出现角色重复、布局遮挡和 Codex 状态误用。建议删除菜单，而不是继续美化它。

## Step review

1. **休眠态 — 基本健康**
   - 优点：520px 尺寸克制，睡姿与胶囊关系自然，紫/青/粉图标容易区分。
   - 风险：唱歌和换装尚不可用，却占据三分之二主操作；Codex 状态块也比真正的主操作更醒目。

2. **三点菜单 — 不健康，建议删除**
   - 菜单包含字幕、暂停、结束、缩小，但只有缩小在休眠态可用；其余三个禁用图标形成无效信息。
   - 暂停只停止麦克风监听，与左侧麦克风按钮重复，并不暂停思考或语音播放。
   - 结束只清理当前会话并返回休眠；可用自动回到休眠或托盘命令替代。
   - 胶囊已经很小，112×44 的二次缩小属于低频能力，放入托盘“隐藏/显示”更合适。
   - 字幕与语音优先方向冲突；如需无障碍字幕，应作为设置中的持久偏好，而不是常驻按钮。

3. **Listening — 不健康**
   - 2D 立绘约 270×613，明显压过 520×108 胶囊并在画布底部被裁切。
   - 2D 立绘和坐姿 8-bit 同时出现，产生两个视觉主角；坐姿人物还盖住 Codex 文案。

4. **Thinking / Codex Working — 不健康**
   - 8-bit 笔记本姿势直接遮住 `Codex / Generating…`，关键状态无法完整阅读。
   - 当前 `Codex Working` 实际由普通对话的 Thinking/Speaking 状态触发，并非真实 Codex 任务，语义不可信。

## Prioritized findings

- **[P1] 删除 `⋮` 与四项菜单。** 它们是重复或低频控制，增加理解成本。不要放装饰性的 Apple 三色点；没有窗口行为的点会形成假按钮。
- **[P1] 活跃态只保留一个人物系统。** 按既定产品方向，休眠显示 8-bit；唤醒后让 2D 立绘出现并隐藏小 8-bit。2D 立绘建议约 170px 宽、360–420px 高，贴近胶囊左侧且不裁切。
- **[P1] Codex 只显示真实 Codex 状态。** DeepSeek 对话的 Thinking/Speaking 不得驱动 `Generating…`；未接入时恒为 `Ready/Standby`。
- **[P2] 把麦克风变成唯一会话控制。** Idle→开始聆听；Listening→停止并回休眠；Thinking→取消；Speaking→打断并重新聆听。无需单独暂停或结束按钮。
- **[P2] 主点击区不足。** 三个功能按钮为 36×36，三点为 40×40，低于桌面触控友好的 44×44；图形可维持 22–24px，但热区应增至至少 44px。
- **[P2] 未实现功能占据主层级。** MVP 建议暂时隐藏唱歌和换装；若必须保留，应降级为低亮未来入口，不能与语音入口同权重。
- **[P3] 光谱描边仍偏游戏 HUD。** Apple 式克制方向应减弱连续外发光，保留 1px 冷色描边和左右局部色彩即可。

## Recommended capsule anatomy

- 左侧：唯一主操作麦克风，44px 热区。
- 中间：留白，不放会话控制；人物不得覆盖信息。
- 右侧：真实 Codex 状态，建议约 170–180px 宽。
- 休眠：仅睡姿 8-bit。
- 活跃：仅 2D 立绘；胶囊通过麦克风颜色和 Codex 状态表达系统阶段。
- 系统托盘：设置、字幕偏好、隐藏/显示、彻底退出程序。

## Accessibility risks and limits

- 当前 aria-label 完整，键盘语义基础可用。
- 仍需实测焦点可见性、屏幕阅读器读序、Windows 150%/200% 缩放和真实透明桌面上的对比度。
- 本次未验证真实 Scribe、DeepSeek、ElevenLabs 音频过程；对暂停含义的判断来自当前前端行为与状态机。
